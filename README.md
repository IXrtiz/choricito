# Choricito

Robot torito en 3D (Three.js) con diseño infantil, basado en el modelo de LEGO EV3.

- **Ver a Choricito**: enciende la cámara y muestra a Choricito sobre la imagen.
- **Caminar**: mueve las patas y dice "¡Hola, amigo!".
- **Mugir**: mueve los cuernos y hace "¡Muuu!".
- **Dar vueltas**: gira el modelo con música alegre.

Abre `index.html` con un servidor HTTPS (por ejemplo GitHub Pages) para que funcione la cámara.
